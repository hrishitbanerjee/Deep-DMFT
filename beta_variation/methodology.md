# Methodology

A long short-term memory (LSTM) sequence-to-sequence autoencoder was trained to predict the imaginary part of the interacting self-energy, Im Σ(iω), from the non-interacting Green's function, Im G₀(iω), across a range of inverse temperatures β, using CT-HYB dynamical mean-field theory (DMFT) calculations for SrVO₃ (SVO) as training data. Input and output spectra were sampled on a uniform Matsubara frequency grid spanning the positive window (0, 10) eV, retaining 64 frequency points per sample. Because the paramagnetic SVO ground state renders all six t₂g spin–orbital channels equivalent, each β value yields a single independent physics sample; accordingly, one representative channel per β was retained prior to splitting to avoid artificial replication of training data. The dataset of eight β values (β = 20, 30, 40, 50, 60, 70, 80, 90 eV⁻¹) was partitioned into a training set (β = 20, 40, 60, 80, 90 eV⁻¹), a held-out validation set (β = 50 eV⁻¹), and a test set of two unseen temperatures (β = 30 and 70 eV⁻¹) used exclusively to assess interpolation. All input and target spectra were standardised using the mean and standard deviation computed from the training partition, ensuring scale-invariant loss gradients across the frequency window. The model encoder compressed each conditioned input sequence—formed by concatenating Im G₀(iω) with a two-component temperature label [β̃, β̃⁻¹], where β̃ = (β − β_min)/(β_max − β_min)—into a fixed-dimensional latent representation via a single-layer LSTM, with dropout applied after the encoder state; the decoder reproduced the target sequence from this state using a second LSTM followed by a time-distributed linear projection. The network was trained by minimising mean-squared error in the normalised target space using the Adam optimiser, with early stopping (patience 40 epochs, up to 1000 epochs maximum) monitoring validation loss on the held-out β = 50 sample. Model performance was quantified by the relative root-mean-square (RMS) residual between predicted and reference Im Σ(iω) curves, evaluated in physical units following inverse standardisation, and compared against a linear interpolation baseline constructed from the two nearest training β values.
